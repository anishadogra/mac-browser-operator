# Instagram web

- Account: check the handle in the sidebar or profile link before anything. Switch with the account switcher (the first click after a page load often does nothing; an account may sit below the fold, so `find` plus `scroll_to`), and switch back when done.
- Comment: `t = document.querySelector('textarea[aria-label^="Add a comment"]')`, `__bo.setValue(t, LINE)`, re-query the textarea and require `value === LINE`, then `__bo.fire` the `div[role=button]` whose text is exactly "Post" inside `t.closest('form')`. Reload and confirm the comment under the account's handle, or in `/your_activity/interactions/comments/`. Plain `computer type` lost keys in two of three tries.
- DM: open `/direct/t/<thread key>/`, confirm "<handle> · Instagram" in the page text, `__bo.paste` into `div[contenteditable="true"][data-lexical-editor]`, hash-check, then `__bo.fire` on `div[role="button"][aria-label="Send"]` and take a screenshot (a link adds a preview card, so the bubble text differs). Message requests need "Accept" first, which is the person's call because it shows read status.
- Inbox without "seen": read the lists only. Rows are `div[role=button]` on `/direct/inbox/`, `/direct/requests/` and `/direct/partnerships/`; `__bo.fiber(row, 'threadKeyForSelection')` or `'viewerThreadRef'` gives the thread key and `last_activity_timestamp_ms`. Full history requires opening the chat, which sends a read receipt. The old `/api/v1/direct_v2/` endpoints answer 404 since October 2026.
- Lazy lists stall in background tabs: override `document.visibilityState` to `'visible'`, dispatch `visibilitychange`, scroll, take a tiny screenshot (scale 0.1) to force a frame, wait 2 s, harvest.
- Bio: ✅ is rejected with only a small toast ("You can't use check marks"); hook the `/api/v1/web/accounts/edit/` response to read the reason. The bio box needs real typing after a coordinate click; verify `textarea#pepBio` before Submit. The display name lives in Accounts Centre (30 characters, 2 changes per 14 days).
- Reel on web: choose "Original" in the crop menu (the default is a 1:1 square), add a custom cover in the Edit step's file input, paste a long caption. `file_upload` caps at 10 MB and Instagram's CSP blocks fetches from localhost.
- Owner-only numbers: in the logged-in tab, `fetch('/api/v1/media/<pk>/info/', {headers: {'X-IG-App-ID': '936619743392459'}})` returns play, like and comment counts. Read-only, and it uses their session, so ask first.
- A public profile without any browser: `curl` the profile URL with a Googlebot user agent; the HTML embeds the latest posts and the follower count.
- API publishers post only to Professional accounts; personal accounts post through the web UI.
- Download buttons that third-party extensions add to tiles send media to outside servers. Leave them alone.
