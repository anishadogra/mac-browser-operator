# Gemini web images

- Sidebar › Images. Set Aspect ratio and Count on that page before every send; both reset when the page reloads.
- The reliable setup was the Flash model with Low thinking. Pro with High thinking often answered in text or stalled for minutes, and a count above 1 hung.
- Prompts: start with "Generate an image:". Write exact on-image text in capitals without quotation marks (quotes get printed). Mentioning watermarks or asking to keep a corner plain triggers refusals.
- "Download full size image" (find it, then a ref click) gives the full file, for example 2752×1536 for 16:9; the inline preview and Copy image are 1024 px. Take only files written to ~/Downloads in the last 2 minutes, because an older copy can arrive first.
- Paid plans add a visible sparkle mark at the bottom right. Editing an image in Gemini redraws the old mark as content, so generate a fresh image instead.
- Outages happen (every request failing for about 30 minutes) and clear by themselves.
